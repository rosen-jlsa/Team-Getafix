# School Inventory Management System

Team Getafix project for tracking school inventory. The repository includes frontend and backend work, an API folder, and a more complete PHP application in `school-inventory-system-final/`.

## Start here

- [`school-inventory-system-final/README.md`](school-inventory-system-final/README.md) — application overview.
- [`school-inventory-system-final/INSTALL.md`](school-inventory-system-final/INSTALL.md) — installation instructions.
- [`DEPLOYMENT_GUIDE.md`](DEPLOYMENT_GUIDE.md) — deployment notes.

## Repository layout

- `Frontend/` and `Backend/` — earlier application work.
- `SchoolInvetoryAPI/` — API implementation.
- `school-inventory-system-final/` — PHP application with configuration, public entry point, services, and Composer files.

**Security note:** Deployment documentation and example environment files contain sample credentials. Replace all defaults before deploying and keep real secrets outside Git. The deployment guide also lists known issues, so validate the application in your own environment before production use.
